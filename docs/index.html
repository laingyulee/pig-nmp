Install in Seconds数秒内开始安装

Debian 11/12 or Ubuntu 20.04–24.04 LTS · x86_64 · Root access required.支持 Debian 11/12、Ubuntu 20.04–24.04 LTS · x86_64 · 需要 root 权限。

1

Clone the repository克隆仓库

$ git clone https://github.com/laingyulee/pig-nmp.git
2

Launch the installer运行安装器

$ # Interactive menu
$ sudo bash pig-nmp.sh

$ # Or quick install everything
$ sudo bash pig-nmp.sh install
3

Create a virtual host创建虚拟主机

Follow the wizard to set up your domain, PHP version, SSL, and rewrite rules.跟随向导配置域名、PHP 版本、SSL 和 rewrite 规则。

$ sudo bash pig-nmp.sh vhost

Command Reference命令参考

Every component has its own management menu. Pass it as an argument.每个组件都有独立的管理菜单，作为参数传入即可。

pig-nmp.sh

Interactive main menu with status overview.交互式主菜单，显示组件状态总览。

sudo bash pig-nmp.sh

pig-nmp.sh nginx

Install, configure, and manage Nginx.安装、配置和管理 Nginx。

sudo bash pig-nmp.sh nginx

pig-nmp.sh php

Multi-version PHP management & extension installer.多版本 PHP 管理及扩展安装。

sudo bash pig-nmp.sh php

pig-nmp.sh mysql

MySQL/MariaDB install, secure, databases.MySQL/MariaDB 安装、安全配置、数据库管理。

sudo bash pig-nmp.sh mysql

pig-nmp.sh ssl

Let's Encrypt or self-signed SSL certificates.Let's Encrypt 或自签 SSL 证书。

sudo bash pig-nmp.sh ssl

pig-nmp.sh status

Dashboard: OS, services, ports, resource usage.系统面板：操作系统、服务状态、端口、资源使用。

sudo bash pig-nmp.sh status
