Install in Seconds数秒内开始安装

Debian 11/12 or Ubuntu 20.04–24.04 LTS · x86_64 · Root access required.支持 Debian 11/12、Ubuntu 20.04–24.04 LTS · x86_64 · 需要 root 权限。

1

Clone the repository克隆仓库

$ git clone https://github.com/laingyulee/pig-nmp.git
2

Launch the installer运行安装器

$ # Interactive menu
$ sudo bash pig-nmp.sh

$ # Or quick install everything
$ sudo bash pig-nmp.sh install
3

Create a virtual host创建虚拟主机

Follow the wizard to set up your domain, PHP version, SSL, and rewrite rules.跟随向导配置域名、PHP 版本、SSL 和 rewrite 规则。

$ sudo bash pig-nmp.sh vhost

Main Menu主菜单

Six core workflows — launch from one entry point.六大核心流程，统一入口启动。

1Install / Update Components安装 / 更新组件

Add or upgrade Nginx, PHP, MySQL, MariaDB, Redis.添加或升级 Nginx、PHP、MySQL、MariaDB、Redis。

2Manage Virtual Hosts管理虚拟主机

Create, list, delete vhosts with PHP version & SSL selection.创建、列出、删除虚拟主机，选择 PHP 版本和 SSL。

5System Status & Manager系统状态与管理
